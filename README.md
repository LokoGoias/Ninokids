# Ninokids

🔗 **Política de Privacidade publicada em:** https://lokogoias.github.io/Ninokids/

## Política de Privacidade (Google Play)

Este aplicativo infantil foi desenvolvido com base em **Privacy by Design**.

- Funciona de forma **100% offline e local**.
- Não possui servidor (backend) nem banco de dados.
- Não há cadastro, login ou campos de texto livre.
- Não solicita permissões de câmera, microfone ou armazenamento.
- Não utiliza SDKs de terceiros nem redes de anúncios.
- **Não coleta, processa, armazena ou transmite dados pessoais ou estatísticos.**
