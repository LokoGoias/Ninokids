# Ninokids

## Política de Privacidade (Google Play)

Este aplicativo foi desenvolvido para o público infantil com base no princípio de **Privacy by Design**.

### 1. Coleta de dados

O aplicativo **não coleta** dados pessoais, dados de identificação ou dados estatísticos.

### 2. Funcionamento do aplicativo

- O aplicativo opera de forma **100% offline e local**.
- Não existe infraestrutura de servidor (backend).
- Não há banco de dados remoto.

### 3. Cadastro e entrada de informações

- Não há formulários de cadastro.
- Não há login.
- Não há campos de texto livre para inserção de dados pessoais.

### 4. Permissões e integrações

- O aplicativo não solicita permissões de hardware, como câmera, microfone ou armazenamento.
- O aplicativo não utiliza SDKs de terceiros.
- O aplicativo não integra redes de anúncios.

### 5. Compartilhamento de dados

Como não há coleta de dados, **nenhuma informação é processada, armazenada ou transmitida** a terceiros.
